# Account Security Policy

## Overview
This policy outlines security protocols for protecting customer accounts and handling security-related inquiries.

## Identity Verification Requirements

### Standard Verification (Low-Risk Inquiries)
For balance inquiries, general questions, statement requests:
- Last 4 digits of SSN OR
- Date of birth AND zip code OR
- Answer to security question

### Enhanced Verification (High-Risk Actions)
For address changes, contact updates, beneficiary changes, large transfers:
- Full SSN verification
- Two-factor authentication code
- Verbal password (if set up)
- May require callback to registered phone number

### Maximum Security (Critical Actions)
For account closure, wire transfers > $10,000, adding new authorized users:
- All Enhanced Verification requirements
- Manager approval
- 24-hour delay option offered
- Written confirmation sent

## Red Flags for Fraud

### Identity Theft Indicators
- Customer doesn't know basic account information
- Calling from unrecognized number repeatedly
- Urgency to change contact information
- Recent address change followed by unusual activity
- Multiple failed login attempts

### Account Takeover Signs
- Sudden change in transaction patterns
- New devices logging in from unusual locations
- Password reset requests from unknown email
- Contact information changed without customer initiation

### Social Engineering Attempts
- Caller claims to be from another department
- Pressure to bypass security procedures
- Requests for internal system information
- "Testing" calls about security procedures

## Immediate Actions for Suspected Fraud

### Step 1: Do Not Proceed
- Stop the transaction or request
- Do not change any account information
- Do not provide any account details

### Step 2: Secure the Account
- Place temporary freeze on account
- Flag account for fraud review
- Document the interaction in detail

### Step 3: Verify Legitimate Customer
- Callback to registered phone number
- Send alert to registered email
- Require in-person verification if needed

### Step 4: Report
- File internal fraud report
- Escalate to fraud team
- Notify customer through secure channel

## Account Lockout Procedures

### Temporary Lockout (3 failed attempts)
- 30-minute automatic lockout
- Customer can self-unlock via email/SMS code
- No agent action required

### Extended Lockout (5 failed attempts)
- 24-hour lockout
- Agent can unlock after Enhanced Verification
- Requires password reset

### Security Lockout (Fraud Suspected)
- Indefinite lockout
- Requires fraud team review
- Customer must verify identity through secure channel

## Password and Authentication

### Password Requirements
- Minimum 12 characters
- Must include: uppercase, lowercase, number, special character
- Cannot reuse last 10 passwords
- Expires every 90 days (optional for customers)

### Two-Factor Authentication
- SMS code (default)
- Authenticator app (recommended)
- Hardware key (available for high-value accounts)
- Backup codes for account recovery

## Data Protection

### What We NEVER Ask For
- Full SSN over email or chat
- Full card number over email
- Password or PIN
- One-time security codes "to verify"

### What We Can Discuss
- Last 4 of SSN (for verification)
- Last 4 of card number
- Transaction amounts and dates
- Account balances (after verification)

### Documentation Requirements
- Never write full SSN in case notes
- Mask card numbers (show only last 4)
- Do not copy/paste customer passwords
- Encrypt any exported customer data
